#Tic-Tac-Toe Game

Name : Naitik Sahu

Section : M Section (SA-16)

ERP No. : RU-26-00824

A simple two-player Tic-Tac-Toe game built using Python. Players take turns placing X and O on a 3x3 board.

##Features 
- Two-player gameplay.
- Detects winners and draws.
- Validates player input.  
- Prevents occupied positions.
- Option to play again.

##Technologies Used
- Python 3
- Functions, Loops, Lists, Tuples
- Conditional Statements

## How To Run
1. Install Python 3.
2. Open the project folder in the terminal.
3. Run:

```bash
python tc_tactoe.py
```

## How To Play
- Player X starts first.
- Enter a position between 1 and 9.
- Get three marks in a row, column, or diagonal to win.
- If all positions are filled with a winner, it's a draw.
